# Rulebook · Passport applications (MADE UP)

**Scenario:** B · ICA passport applications

**This rulebook is made up for the course.** It is not ICA's real rules. Do not use it for a real passport application.

It stands in for official requirements, so the prototype has a full set of rules to test against. The group's own rules, from `day1-discover-define/skill-file.md`, are added on top.

## Who counts as a child

- A passport holder **under 14** is a child.
- Age 14 and above is an adult.

## Documents

**Adults** must attach:

- their identity card
- a photo that meets the photo rules

**Children** must attach:

- their birth record
- the identity card of one consenting parent or guardian
- vaccination details *(group rule 1)*
- a photo that meets the photo rules

## Photo

- Taken in the **last 4 months**. A photo taken exactly 4 months ago passes.
- Plain **light blue** background.
- **Both ears** visible.
- Face visible *(group rule 3)*.
- **No tinted glasses or sunglasses.** Clear glasses are allowed.
- **Headgear** is allowed only if it is worn every day and the full face, from chin to forehead, is visible.
- 300 to 400 pixels wide **and** high, and a file under 20 MB *(group rule 2)*. 300 and 400 pass. A file of 20 MB or more fails.

## The group's rules on top

From `day1-discover-define/skill-file.md`, unchanged:

1. For children, passport applications and renewals need vaccination details.
2. The photo should be 300 to 400 pixels. The file is under 20 MB.
3. In the photo, the face should be visible.

## Application types covered

These rules cover only two types: a **new passport** and a **renewal**. Any other type, such as a replacement for a lost or damaged passport, is not covered and goes to an officer.

## When the rules do not decide

- If it is not clear whether a rule is met, escalate to an officer.
- If an application raises something this rulebook does not cover, escalate to an officer.
- Never suggest Approved in either case.
